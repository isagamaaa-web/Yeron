# Yeron Esayas — Personal Portfolio Portal

The production-ready source code for my personal developer portfolio website. This project is engineered with a sleek, minimalist dark aesthetic, optimized for rapid asset loading, raw performance, and seamless user experiences.

Live Link: [yeron.vercel.app](https://yeron.vercel.app)

---

## 🚀 Codebase & Structural Features

* **Immersive 3D Background:** Powered by a lightweight, high-performance **Three.js WebGL** particle field container calibrated for fluid rendering across both desktop and mobile viewports.
* **Multilingual Translation Matrix:** Built-in client-side translation layers mapping text components seamlessly between multiple languages (including English and Amharic) for broad localization control.
* **Interactive State Challenge:** An integrated system riddle engine that leverages browser `localStorage` matrices to securely manage attempt states, executing a strict device lockout UI after 3 failed answers.
* **Minimalist Connection Modal:** A clean, glassmorphic overlay portal mapping dedicated structural nodes directly to verified communication targets (Telegram, Instagram, and Email templates).
